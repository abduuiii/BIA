## 🎯 Current Focus

I am currently developing an **AutoML project using Python and Streamlit**.

The goal is to create a system where a user can upload a dataset and the application automatically:

1. Understands the dataset
2. Identifies the target variable
3. Determines the appropriate ML technique
4. Performs data preprocessing
5. Splits the data
6. Trains suitable ML models
7. Evaluates the models
8. Selects the best-performing model
9. Displays the results
